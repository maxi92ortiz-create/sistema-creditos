Ingresar al sistema

Cómo instalar en mi dispositivo

Android: Chrome → menú ⋮ → Agregar a pantalla principal o Instalar aplicación.

iPhone: Safari → Compartir → Agregar a inicio. Si aparece “Abrir como app web”, activalo.

Windows: Chrome o Edge → menú del navegador → opción para instalar esta página como aplicación.

Preparar los íconos: solo una vez

Descargá las dos imágenes desde estos botones. Después subilas al repositorio de GitHub junto a index.html, sin cambiar sus nombres.

Se instala la entrada de GitHub. Al ingresar se abre el sistema en Google Apps Script. Los cobros y las consultas requieren internet.
